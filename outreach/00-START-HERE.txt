PROBLEM SOLVED:
Previous prospect research found 5 therapy prospects, all turned out inactive/unreachable.
Root cause: NO VALIDATION. This system validates prospects BEFORE adding to outreach.

================================================================================
WHAT YOU GET:
================================================================================

1. AUTOMATED DISCOVERY
   - Searches Psychology Today therapist directory
   - Searches Avvo lawyer directory
   - Validates each prospect before adding

2. VALIDATION SCORING (1-5 scale)
   - Website status (live, redirects, unreachable)
   - Contact info extraction (email, phone)
   - Directory sources (cross-referenced)
   - Content recency
   - Only prospects with score >= 2 added to outreach

3. PROSPECT DATABASE
   - JSON format (machine-readable, for code)
   - CSV export (human-readable, for review/import to CRM)
   - Automatic deduplication

4. PERSONALIZED EMAIL SEQUENCES
   - 3 emails per prospect (Day 1, Day 5, Day 12)
   - A/B test subject lines
   - Customized per prospect type:
     * Therapists: Position as "tech safety" expert
     * Lawyers: Position as digital forensics expert
     * Mediators: Position as mediation value-add
   - Warm, peer-to-peer tone
   - No attachments in first email

5. OUTREACH TRACKING
   - Prevents duplicate emails to same prospect
   - Logs all interactions (sent, replied, converted)
   - Tracks next follow-up date

VALIDATION SCORING (1-5):
================================================================================

Score 5: Very High Confidence
  Website live + email + phone + recent content + 2+ directories

Score 4: High Confidence
  Website live + 1 contact + recent content

Score 3: Moderate Confidence
  Website accessible + some contact info

Score 2: Low Confidence
  Website redirects or unclear status + limited contact

Score 1: Very Low Confidence
  No contact info or unreachable

Default minimum: Score >= 2 (configurable in config.py)

================================================================================
EMAIL SEQUENCE:
================================================================================

Day 1 - Initial Outreach
  Subject: Personalized based on prospect type
  Body: 150-200 words, warm tone, clear CTA ("Would 15-min call make sense?")
  A/B test variant (subject line)

Day 5 - Follow-up 1
  Subject: Friendly reminder
  Body: Brief, reinforces value prop
  
Day 12 - Follow-up 2 (Breakup Email)
  Subject: "Last note" or "Final message"
  Body: Direct, sets expectation that this is final contact

All emails:
  - No attachments (cleaner inbox)
  - Personalized (prospect name, specialties)
  - Warm peer-to-peer tone
  - Clear next step
  - Easy to reply to

TYPICAL WORKFLOW:
================================================================================

MONDAY: Research
  python run_research.py --type therapist --state CA --city "Los Angeles" --count 20
  python run_research.py --type lawyer --state CA --count 15

TUESDAY: Review
  Open prospects.csv in Excel/Sheets
  Filter by score >= 3
  Mark any to skip
  Save

WEDNESDAY: Generate & Send
  python outreach_manager.py --action generate --limit 10
  Copy/paste emails into your email client
  (Or integrate with Gmail API for auto-send)

THURSDAY: Track
  python outreach_manager.py --action mark-sent --email prospect@email.com
  [Repeat for all sent emails]

FRIDAY (Day 5 & 12): Follow-ups
  python outreach_manager.py --action followup-schedule --days 5
  [Send follow-up 1 emails]
  
  python outreach_manager.py --action followup-schedule --days 12
  [Send final breakup emails]

ONGOING: Stats & Optimization
  python outreach_manager.py --action stats
  python outreach_manager.py --action audit
  [Review what's working, iterate]

DATABASE STRUCTURE:
================================================================================

prospects.json (Machine-readable):
  Keyed by "email: Name"
  Full prospect records with all metadata
  Deduplication happens here
  Outreach history preserved

prospects.csv (Human-readable):
  Columns: name, title, practice_name, email, phone, website, specialties,
           state, city, validation_score, validation_notes, outreach_status
  Sorted by validation_score (highest first)
  Easy import to CRM (Salesforce, HubSpot, Pipedrive)
