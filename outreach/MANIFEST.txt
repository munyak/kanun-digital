KNOWN LIMITATIONS
================================================================================

Web Scraping:
  - Psychology Today uses JavaScript (may need Selenium)
  - Avvo has anti-bot measures
  - Some sites have paywalls/login walls
  - Workaround: Hand-curate top results or use APIs

Contact Info Extraction:
  - Regex-based (misses contact forms)
  - No phone validation
  - Workaround: Manually add for valuable prospects

Email Sending:
  - System generates emails, doesn't send them
  - Copy/paste into email client
  - Workaround: Integrate Gmail API, SendGrid, or Mailgun

Follow-up Automation:
  - Manual scheduling (Day 5, 12)
  - Workaround: APScheduler for automation

Mediators:
  - No dedicated directory (use Psychology Today search)
  - Workaround: State bar, IMTA registry, Google search
